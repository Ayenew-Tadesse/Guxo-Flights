# Hid-Go

A UI/UX portfolio prototype: a full-featured Ethiopian domestic flight booking mobile app, built as a single self-contained HTML file (vanilla JS, no frameworks).

## Features

- Sign up / log in with persisted account data
- Round-trip and one-way flight search across Ethiopian domestic airports
- Results list with fare comparison, filters, and date-strip pricing
- Fare tier selection (Basic / Standard / Flex) and seat map picker
- Payment flow (Telebirr, CBE Birr, cards) with a mock confirmation
- Trip management, check-in, boarding pass, notifications, and profile screens
- Light/dark theme support and a responsive layout from phone to large desktop widths

## Stack

Plain HTML, CSS, and JavaScript — no build step, no dependencies. Open `index.html` in a browser to run it.
